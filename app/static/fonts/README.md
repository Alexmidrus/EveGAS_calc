# Шрифты интерфейса

Файлы, на которые ссылается `@font-face` в `app/static/style.css`. Раздаются
со своего хоста: внешних запросов в рантайме у приложения нет, страница
обязана открываться без интернета (SPEC §10.1 и §10.4).

## Что здесь лежит

| Файл | Семейство | Алфавит | Размер |
|------|-----------|---------|--------|
| `archivo-latin.woff2` | Archivo | латиница | 34 КБ |
| `archivo-latin-ext.woff2` | Archivo | расширенная латиница | 32 КБ |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | латиница | 31 КБ |
| `jetbrains-mono-latin-ext.woff2` | JetBrains Mono | расширенная латиница | 11 КБ |
| `jetbrains-mono-cyrillic.woff2` | JetBrains Mono | кириллица | 8.7 КБ |
| `jetbrains-mono-cyrillic-ext.woff2` | JetBrains Mono | расширенная кириллица | 1.6 КБ |

Итого 121 КБ, и целиком они не качаются никогда: `unicode-range` режет
загрузку по алфавитам. На русской странице браузер берёт три файла из шести —
расширенные подмножества нужны только под редкие символы.

Файлы **вариативные**: один файл на подмножество обслуживает все начертания,
поэтому в `@font-face` стоит `font-weight: 100 900` (Archivo) и `100 800`
(JetBrains Mono) диапазоном, а не по числу на каждое. Отдельных файлов
под 400, 600 и 700 не нужно — браузер интерполирует из того же файла.

## Откуда взяты

Google Fonts, семейства `Archivo` и `JetBrains Mono`, скачаны с
`fonts.gstatic.com` по адресам из ответа `fonts.googleapis.com/css`.
Лицензия обоих — SIL Open Font License 1.1, вложение файлов в репозиторий
она разрешает. Забирать нужно именно файлы, а не `<link>` на CDN: ссылка
на сторонний хост нарушает §10.1 и ломает работу без интернета.

Обновлять их незачем: шрифт — не зависимость, которая протухает.

## Известное ограничение: у Archivo нет кириллицы

Google Fonts отдаёт Archivo только в подмножествах `latin`, `latin-ext`
и `vietnamese`. Кириллического подмножества у семейства нет вообще.

Значит, Archivo набирает на странице только латиницу — имя продукта,
`by EveCraft`, бейдж `Compressed`, `sell` / `buy`. **Весь русский текст
интерфейса** — подписи полей, заголовки колонок, сноски — падает
на `system-ui`. Проверено замером в браузере: строка «Параметры» в Archivo
и в заведомо несуществующем шрифте имеет одинаковую ширину, то есть шрифт
не применяется.

Числа этим не задеты: они набираются JetBrains Mono, у которого кириллица
есть, и подписи вроде «ISK/м³» или «сжатый» выглядят как задумано.

Как это чинить, если понадобится: добавить в стек текстового шрифта
кириллическое семейство под OFL — `Golos Text` или `Inter` — вторым после
Archivo. Тогда кириллица получит предсказуемое начертание вместо того,
что окажется в системе у пользователя. Это отдельное решение по оформлению,
а не техническая правка: оно меняет то, как выглядит интерфейс.
