## 1. Сжатие и разжатие газа

### Сжатие

- Соотношение по **количеству — 1:1**. Один юнит сырого газа даёт один юнит сжатого.
- Соотношение по **объёму — 10:1**. Сжатый юнит занимает ровно 1/10 объёма сырого.
- Сжатие **без потерь**.
- Выполняется только в космосе модулем Gas Compressor на Porpoise / Orca / Rorqual.
  Структуры газ сжимать не умеют. *Для калькулятора это не важно — мы только покупаем.*

### Разжатие

- Сжатый газ **нельзя использовать в чертежах и реакциях напрямую**. Перед производством
  его обязательно надо разжать. Это и есть причина существования калькулятора.
- Разжатие выполняется на Upwell-структуре со Standup Reprocessing Facility.
  NPC-станции разжимать не умеют.
- Разжатие **всегда с потерями**. Достичь 100% невозможно.
- **Налога за разжатие нет.** Владелец структуры не может взять процент за эту операцию.

### Эффективность разжатия

```
eta = 0.80 + structure_bonus + 0.01 * gde_level
```

| Компонент                          | Значение |
|------------------------------------|----------|
| База                               | 0.80     |
| Upwell без бонуса (Astrahus и др.) | +0.00    |
| Athanor                            | +0.04    |
| Tatara                             | +0.10    |
| Навык Gas Decompression Efficiency | +0.01 за уровень, максимум +0.05 |

Предельные значения: минимум **0.80**, максимум **0.95** (Tatara + GDE V).

Валидация: `gde_level` — целое 0..5. Тип структуры — enum `upwell | athanor | tatara`.

### Округление

Дробные юниты при разжатии **отбрасываются вниз**:

```
raw_out = floor(compressed_qty * eta)
```

Минимум 2 юнита сжатого газа нужно, чтобы разжатие дало хоть что-то. На производственных
объёмах погрешность округления — один юнит, но в формуле её надо соблюсти.

Обратная задача (сколько сжатого купить, чтобы получить N сырого):

```
compressed_qty = ceil(N / eta)
```

| Fullerite-C72   | 2                | 0.2               |

### Mykoserocin — хайсек/лоусек/нулл, synth-бустеры и neurolink enhancers

Восемь «цветов»: Amber, Azure, Celadon, Golden, Lime, Malachite, Vermillion, Viridian.
Объём сырого — **10 м³**, сжатого — **1.0 м³**.

### Cytoserocin — лоусек и нулл, боевые бустеры

**Десять** цветов: те же восемь плюс Chartreuse и Gamboge. Объём сырого — **10 м³**,
сжатого — **1.0 м³**.

Два лишних цвета — не опечатка. Здесь раньше значилось восемь, по аналогии
с Mykoserocin; сверка с SDE (14.08.2026, `tools/build_gases.py`) показала десять
опубликованных типов Cytoserocin с корректной парой сжатого газа. Их сжатые
type_id 62388 и 62389 как раз закрывали дыру между Celadon и Golden.

Полный машиночитаемый справочник с type_id — `data/gases.json`, он генерируется
скриптом из SDE и является источником истины по составу семейств.

## 4. Экономическая модель

### Обозначения

| Символ | Смысл |
|--------|-------|
| `N`    | нужно юнитов **сырого** газа (целевое количество для производства) |
| `P`    | цена за один юнит выбранной формы газа, ISK |
| `V`    | объём одного юнита **сырого** газа, м³ |
| `r`    | ставка доставки для конкретного хаба, ISK/м³ |
| `b`    | брокерская комиссия, доля (например 0.015) |
| `eta`  | эффективность разжатия, доля |
| `c`    | обеспечение (collateral), доля от стоимости газа (например 0.005 = 0.5%) |

### Четыре сценария на каждый хаб

Итого 5 хабов × 4 сценария = **20 строк** в результирующей таблице.

| Сценарий         | Сколько покупаем      | Объём груза     | Комиссия брокера |
|------------------|-----------------------|-----------------|------------------|
| сырой · sell     | `N`                   | `N * V`         | нет              |
| сырой · buy      | `N`                   | `N * V`         | есть             |
| сжатый · sell    | `ceil(N / eta)`       | `qty * V / 10`  | нет              |
| сжатый · buy     | `ceil(N / eta)`       | `qty * V / 10`  | есть             |

**Почему у sell нет комиссии:** покупатель, забирающий товар с sell-ордера, не платит
ничего. Брокерский сбор берётся при **выставлении** собственного buy-ордера, поэтому он
есть только в buy-сценариях. Налог с продаж (sales tax) в этой задаче не участвует вовсе —
мы только покупаем.

### Доставка

```
freight = volume_m3 * rate_per_m3 + purchase * c
```

Доставка складывается из двух частей: платы за объём и надбавки за обеспечение.
Вторая — процент от стоимости самого груза: перевозчик берёт риск потерять газ,
и плата за этот риск пропорциональна тому, сколько газ стоит.

Ставка `rate_per_m3` **своя для каждого хаба** — маршруты до производственной точки разные.
Это ключевой параметр: одинаковая ставка на все хабы делает таблицу бессмысленной.

### Обеспечение

Пользователь вводит **одно число — процент** (в интерфейсе в процентах, в расчёте долей).
База — стоимость газа в этом сценарии, `purchase = qty * P`.

Отсюда два следствия, важных для понимания таблицы:

- Надбавка **разная в каждой строке**: где газ дороже, там и обеспечение больше. Она влияет
  на порядок сортировки, а не просто сдвигает все итоги на одну величину.
- База — **чистая стоимость газа, без брокерской комиссии**. Комиссия платится бирже,
  она не едет в трюме и в объявленную стоимость груза не входит.

Типовое значение — 0.5%, оно же значение по умолчанию в форме. Но это не игровая константа:
перевозчики просят разное, поэтому число задаёт пользователь.

### Итоговая стоимость сценария

```
purchase = qty * P
broker   = purchase * b        (только для buy-сценариев, иначе 0)
freight  = volume_m3 * r + purchase * c
total    = purchase + broker + freight
```

### Главная метрика

```
isk_per_useful_unit = total / N
```

Именно по ней сортируется таблица, по возрастанию. Знаменатель — всегда `N`, целевое
количество сырого газа, одинаковое для всех сценариев. Это и делает строки сравнимыми:
потери на разжатии уже сидят в числителе через увеличенное `qty`.

### Точка безубыточности

При какой цене сжатого газа он выгоднее сырого в том же хабе (без учёта брокера и обеспечения):

```
P_compressed_breakeven = eta * (P_raw + V * r) - V * r / 10
```

Выводится в интерфейсе отдельной строкой на каждый хаб — это цифра, которую удобно
держать в голове весь игровой день.

## 5. Контрольный пример для тестов

Используй его в `tests/test_calculator.py` как основной кейс.

**Вход:**

```
газ:            Fullerite-C320  (V = 5 м³, сжатый 0.5 м³)
N:              50 000
структура:      Athanor
GDE:            5
eta:            0.89
брокер:         0.015
обеспечение:    0.5% от стоимости газа (c = 0.005)
ставки, ISK/м³: jita 500, amarr 700, dodixie 600, rens 900, hek 850
```

**Промежуточные значения:**

```
qty сжатого   = ceil(50000 / 0.89) = 56 180
объём сырого  = 50 000 * 5   = 250 000 м³
объём сжатого = 56 180 * 0.5 = 28 090 м³
потери при разжатии = 56 180 - 50 000 = 6 180 юнитов (11%)
```

Надбавка за обеспечение считается в каждой строке своя — общего числа здесь быть не может.

**Ожидаемые результаты** (цены условные, для проверки арифметики).
Колонка «Доставка» — полная: объём × ставка плюс надбавка за обеспечение.

